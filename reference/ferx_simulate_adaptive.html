Simulate state-reactive (adaptive / feedback) dosing

Description

Runs a forward simulation in which the dosing regimen is decided at run time by the model file’s [adaptive_dosing] block - a declarative first-matching-rule controller that reads the simulated (optionally assay-noised) state at each decision time and titrates the next dose. This is the file-driven therapeutic-drug-monitoring / feedback-dosing path; the plain [ferx_simulate](ferx_simulate.qmd) replays a fixed regimen from the data instead.

Usage

ferx_simulate_adaptive(
  model,
  data = NULL,
  n_sim = 1L,
  seed = 42L,
  verify = TRUE,
  max_decisions = 0L,
  fit = NULL,
  etas = NULL,
  unmatched = c("refuse", "draw")
)

Arguments

  • model: Path to a .ferx model file containing an [adaptive_dosing] block
  • data: Path to a NONMEM-format CSV, or a data.frame (see [ferx_fit](ferx_fit.qmd)): an observation grid, any covariates, and optionally a pre-scheduled base regimen (dose rows). When omitted, the data fit was fitted to (when fit is given and its data can still be found), otherwise the model file’s [data] block (path = ...). The DV column may be left empty (. / NA) on the sampling rows - the DV is what the simulation produces, so an empty cell means “simulate here” (a placeholder value is not needed). Rows marked MDV = 1 are excluded, as always. Kept empty-DV records are reported in the simulation_warnings attribute and re-emitted as an R warning: ferx_fit() skips those same records, so simulated rows at those times have no counterpart in a fit’s sdtab (do not overlay the two, e.g. in a VPC). Every other data-reader diagnostic the engine raises for data - a dose that never landed, a covariate with no value for some subjects, and so on - travels the same channel, as do the model/data and ODE-solver findings ferx_simulate() reports. A dataset with no dose rows raises no W_NO_DOSES here: the controller supplies the regimen.
  • n_sim: Number of simulation replicates
  • seed: Random seed for reproducibility
  • verify: Run the frozen-schedule replay verifier after every (subject, replicate) (default TRUE). A divergence is a hard error, not a warning: it means the realized dose ledger does not reproduce the trajectory, so the result is not trustworthy.
  • max_decisions: Per-run cap on the number of decision points (the runaway / closed-loop guard). 0 (default) keeps the engine default.
  • fit: Optional ferx_fit result. When provided, the simulation runs at the fitted estimates (fit$theta, fit$omega, fit$sigma, the IOV omega when the model has one, and the fitted block_sigma correlations) instead of the model file’s initial values, as in [ferx_simulate](ferx_simulate.qmd). A theta level block is laid out as the fit laid it out (fit$theta_levels), so a design that observes only some of the fit’s levels reads each level’s own fitted value; a level the fit never observed is an error. Random effects are still drawn from the fitted omega - a subject’s own individual estimates are not carried over, and the per-occasion kappas are drawn per decision window, so the fit’s IOV occasion rule plays no part. To simulate each subject at its own estimates instead, pass etas = fit$ebe_etas.
  • etas: Optional data frame of each known subject’s own random effects: an ID column plus one column per eta, named and ordered as the model declares them (fit$ebe_etas has exactly this shape, so ferx_simulate_adaptive(model, fit = fit, etas = fit$ebe_etas) simulates every fitted subject at its EBEs). A subject with a row is simulated at those etas in every replicate instead of a draw from omega; its kappas (IOV, drawn per decision window) and the controller’s assay error are still drawn, so without either its replicates are identical. Rows are matched to the data’s subjects by ID; a row whose subject is not in the data is ignored. A row gives every eta of the model - there is no partial row, since under a block omega the missing eta would need a conditional draw. Each supplied subject still consumes its eta draw, so the drawn subjects get the etas the same seed gives without etas. Works with and without fit. Refused, coded E_SUPPLIED_ETAS: eta columns that are not the model’s names in its order, a repeated ID, a non-finite value, and a [mixture] model (each subject’s eta was estimated under its own class, but the run draws each subject’s class). A repeated column name is refused before the engine is called. Supplied etas are point estimates treated as exact, which is optimistic for a subject with few observations (high shrinkage).
  • unmatched: What to do with a data subject that has no row in etas: "refuse" (the default) errors with E_SUPPLIED_ETAS, listing the subjects; "draw" draws their etas from omega, so known patients and virtual ones run in one population. Under "draw", an etas whose IDs match no data subject ("01" against "1", say) is warned about, since every subject was then drawn. IDs are matched as text; a numeric ID is spelled as a data.frame data writes it. Passing unmatched without etas has no effect and warns.

Details

The data may carry a pre-scheduled base regimen - ordinary dose rows (EVID = 1 or 4, with AMT, and optionally RATE, SS, II) such as a loading or maintenance dose. The controller then augments that standing prescription: at each decision time it reads the simulated (optionally assay-noised) state and appends its own dose. A dose-free base subject (observation grid only) is equally valid - the controller simply supplies the entire regimen. A model without an [adaptive_dosing] block is an error. The dose ledger ($doses) holds controller-issued doses only.Pre-scheduled base doses never appear in it, so $metrics$CUM_DOSE and $metrics$N_DOSESexclude the base regimen (e.g. a 1500 mg loading dose is not counted). The full realized regimen is the union of $doses with the input CSV’s EVID = 1/4 rows. In contrast $trajectories, $decisions, PCT_TIME_IN_WINDOW, and the auc_target attainment metric do reflect the base regimen. A base dose scheduled exactly at a decision time is read pre-dose (the trough), and a base dose scheduled after a stop still lands - a stop ends controller augmentation, not the standing prescription. System resets. An EVID = 3 row zeroes the compartments (and re-seeds any init(state) = expr) at its time; EVID = 4 does the same and then doses. Ordering at a shared time is reset, then dose, then observation. A base regimen combined with resets runs on the constant-covariate path and under a time-varying covariate or IOV. One combination remains rejected with a typed error rather than silently mis-integrated: a steady-state, lag-timed, or modeled-rate (RATE) base dose under a time-varying covariate or IOV (supported on the constant-covariate path). An auc_target metric is accepted on a subject with resets, under a time-varying covariate, a TIME-dependent PK parameter, or IOV: the window AUC is integrated on the run’s own trajectory, so a dose or reset inside a decision window is integrated exactly.

Errors raised by the engine

A model or dataset the engine refuses is an R error, never a NULLresult. Where the engine’s validation pass names the finding, the error has class ferx_engine_error and carries code, block, line and suggestion - the same condition a refused [ferx_fit](ferx_fit.qmd) raises, so one tryCatch(..., ferx_engine_error = ) handler covers every entry point. Its message ends with the code in square brackets and, when there is a suggestion, a hint: ... line, as a refused fit’s does. A failure the validation pass cannot attribute to one diagnostic is raised as an ordinary error carrying the engine’s message.

Concept

simulation

Value

A list of four data frames:

  • trajectories: DRAW, SIM, ID, TIME, CMT, IPRED, DV_SIM, OBSERVED - the per-observation predictions, as in [ferx_simulate](ferx_simulate.qmd) (OBSERVED is NA here: the adaptive path has no time-to-event endpoint). A [mixture] model adds an integer MIXNUM column, the class each subject was drawn into for that replicate; it is absent otherwise.
  • doses: The realized dose ledger, controller-issued doses only (pre-scheduled base doses are excluded): DRAW, SIM, ID, TIME, AMT, CMT, RATE, DECISION, SIGNAL (the value the controller titrated on - assay-noised when with_assay_error), RULE (the rule that fired).
  • decisions: One row per review-grid point including holds: DRAW, SIM, ID, DECISION, TIME, SIGNAL, OUTCOME (“dosed” / “hold” / “not_due” / “stop”), N_DOSED, INTERVAL. “not_due” marks a grid point at which no dose was due under the dosing interval in force (the block declares intervals and start_interval): the controller was not consulted and gave no dose, but SIGNAL still holds what the monitor read. INTERVAL is the dosing interval in force after the decision, NA when the block declares no intervals.
  • metrics: One row per realized run (subject x draw x replicate) - the per-subject outcome summary: DRAW, SIM, ID, CUM_DOSE (sum of controller-issued doses; excludes the base regimen), N_DOSES (controller doses only), N_INCREASES / N_DECREASES (realized dose-change counts, by dose delta), N_HOLDS (consulted decisions that gave no dose; not-due points are not counted), N_NOT_DUE (grid points that were not due), DISCONTINUED, TIME_TO_DISCONT, SIGNAL_MIN / SIGNAL_MAX / SIGNAL_MEAN (over the decisions that recorded a signal), and PCT_TIME_IN_WINDOW - the fraction of signal-bearing decisions whose observed value fell inside the model’s [adaptive_dosing] target_window (NA when no target_window is declared), AUC_TARGET_ATTAINMENT - the fraction of windows between consecutive realized decisions whose area under the monitored signal fell inside the auc_target band (NA when no auc_target is declared, or with fewer than two decisions), ETA_SUPPLIED (TRUE when the run used the subject’s row of etas, FALSE when its eta was drawn), and DOSE_ORACLE (TRUE for a subject whose eta was drawn and whose dose expressions read its drawn individual parameters, under the block’s dose_knowledge = oracle: a perfect-information comparison arm, never a dosing rule).

Examples

ex  <- ferx_example("adaptive_tdm")
res <- ferx_simulate_adaptive(ex$model, ex$data, n_sim = 20L, seed = 1L)
head(res$doses)         # how the dose was titrated per decision
head(res$trajectories)  # the resulting concentration-time profiles

# Subjects 1 and 2 at known etas; the other subjects draw theirs.
known <- data.frame(ID = c("1", "2"), ETA_CL = c(0.3, -0.2))
res <- ferx_simulate_adaptive(ex$model, ex$data, n_sim = 20L, seed = 1L,
                              etas = known, unmatched = "draw")
table(res$metrics$ID, res$metrics$ETA_SUPPLIED)
